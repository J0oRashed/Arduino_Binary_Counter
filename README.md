# Arduino Binary Counter (0–15)

## Project Overview
This project uses an Arduino Uno and four LEDs to represent binary numbers from 0 to 15

## Components
- Arduino Uno
- 4 LEDs
- 4 current-limiting resistors
- Breadboard and jumper wires

## How It Works
Each LED represents one binary digit (bit):
- HIGH (1): LED ON
- LOW (0): LED OFF

The Arduino counts from 0 to 15, calculates the binary digits using arithmetic operations, and displays the result through the four LEDs.

## Technologies
- Arduino
- C/C++
- Binary Number System

- Practicing `for` loops
- Learning integer division and the modulo operator
- Converting decimal numbers to binary using arithmetic
